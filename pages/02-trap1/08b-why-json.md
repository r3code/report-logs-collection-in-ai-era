# Почему JSON и схема, а не «чего попало»

<v-click>

**В ClickHouse можно насыпать чего попало** – Map(String, String), JSON

</v-click>

<v-click>

**Но без схемы запросы не построишь** – что искать?

</v-click>

<v-click>

**Без схемы = OpenSearch** – полный перебор вместо SQL

</v-click>

<v-click>

**Договорились с командами:**

- Все приложения пишут логи в **JSON**
- Следуем **OpenTelemetry SemConv** в названиях полей
- Стандарт предписывает обязательные поля (например `ts` в RFC3339 UTC, не `time` или `dt`)
- **Unified Log Pipeline** переводит логи в OpenTelemetry Logs Data Model для ClickHouse

</v-click>
